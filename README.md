# SRW2 Remake

FC《第2次超级机器人大战》的个人网页重制版，仅供自己游玩。

## 目标功能
- 还原原版地图、机体、战斗规则
- 选关
- 战斗动画开关 / 加速
- 高帧率（平滑移动与补间动画）
- 画面高清化（原版像素 / 高清素材可切换）
- 新增机体

## 运行
```bash
npm install
npm run dev
```
打开 http://localhost:5173 。需要先把 ROM 放到 `rom/srw2.nes`。

当前是原版的网页模拟器，用来对照和逆向；重制版会在此基础上开发。

按 Esc（或鼠标移到右上角点菜单按钮）打开菜单：即时存档、自定义按键、画面大小 / 比例 / 滤镜、加速倍数、帧率显示、全屏。

## 目录
- `rom/`：放自己的 ROM 文件（已在 .gitignore 中排除，不会上传）
- `docs/`：逆向笔记、数据表说明
- `src/emu/`：模拟器补丁（汉化版的 mapper）
- `src/player/`：网页播放器
- `tools/`：素材导出、无界面运行脚本
