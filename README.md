# SRW2 Remake

FC《第2次超级机器人大战》的个人网页重制版，仅供自己游玩。

## 目标功能
- 还原原版地图、机体、战斗规则
- 选关
- 战斗动画开关 / 加速
- 高帧率（平滑移动与补间动画）
- 画面高清化（原版像素 / 高清素材可切换）
- 新增机体

## 运行
```bash
npm install
npm run dev
```
需要先把 ROM 放到 `rom/srw2.nes`。

- **重制版**：http://localhost:5173 （开发中，见 `docs/design.md` 的开发路线）
- **原版模拟器**：http://localhost:5173/emu.html ，用来对照原版和逆向。按 Esc 打开菜单：即时存档、自定义按键、画面设置、加速、全屏

### 重制版操作
| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动光标，同时按两个方向斜走，长按加速 |
| 按住 Shift | 光标高速移动；战斗和敌方回合加速 |
| X / Enter / 空格 | 确定（选单位、移动、菜单确认）；选中单位后直接点敌人 = 自动移动到能打的位置并攻击 |
| Z / Esc / 退格 | 取消 |
| E / Tab，Q | 下一个 / 上一个未行动的我方单位 |
| R | 显示 / 隐藏敌方威胁范围 |
| M | 地图菜单（结束回合等） |
| + / − / 滚轮 | 缩放 |
| 鼠标 | 悬停看信息，点击选择和移动，右键取消 |
| 手柄 | 十字键 / 摇杆移动，A 确定，B 取消，LB/RB 切换单位，Y 敌方范围，X 高速移动 |

## 目录
- `rom/`：放自己的 ROM 文件（已在 .gitignore 中排除，不会上传）
- `docs/`：逆向笔记、数据表说明
- `src/emu/`：模拟器补丁（汉化版的 mapper）
- `src/player/`：原版模拟器的网页播放器
- `src/remake/`：重制版
- `data/`：从 ROM 提取的数据（地图、环境、部署等）
- `assets/original/`：从 ROM 提取的原版素材
- `tools/`：素材导出、无界面运行脚本
