# 原版体验问题清单

测量和截图：`node tools/ux-probe.js`（需要 `node tools/make-rule-states.js` 先生成存档），截图在 `extracted/shots/ux/`（不进仓库，随时可重新生成）。

## 原版的规则问题（供设计参考）

- 反击时射程判定看的是「攻方是否移动过」，攻方移动后用 E 类武器远程攻击时，守方的远程武器无法反击（`docs/notes-rules.md` 1.4）
- 预测击破用「HP < 伤害」，HP 正好等于伤害时预测不算击破，但实际照样击破，AI 因此会低估这种目标
- 敌人移动后只从目标四邻格攻击，远程敌人移动后基本只能近战
- 命中先乘地形、距离再封顶 100，高命中单位几乎无视地形
