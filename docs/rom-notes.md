# ROM 笔记

## 基本信息
- 文件：`rom/srw2.nes`（不进仓库），SHA1 `0f00406be0f5b81b2730802692759c2671cb140a`
- PRG 256KB，CHR 256KB，文件头标 mapper 74，实际行为是 **mapper 194**：外星汉化版的 MMC3 变种，1KB CHR bank 0、1 映射到 2KB CHR RAM，中文字形由程序动态写入
- 游戏会翻转 MMC3 的 CHR A12 反转位，把 RAM 换到 $0000 写字形、再从 $1000 显示，模拟器必须在翻转时立即重映射（实现见 `src/emu/waixing-mmc3.js`）
- 带电池存档，垂直镜像

## CHR 图块分布（`python3 tools/dump_chr.py rom/srw2.nes extracted/chr`）
| bank | 内容 |
|---|---|
| 0 | 英文数字字体、菜单符号、大地图地形图块 |
| 1 | 数字、小图标、部分头像 |
| 2–6 | 驾驶员头像（还需要 PRG 里的拼图表才能拼成完整头像） |
| 7–8 | 大地图上的 SD 小机体 |
| 9 | 背景、云、建筑 |
| 10 | 标题 Logo、星空 |
| 11–12 | 汉化字库（中文字） |
| 13–15 | 杂项、特效、未确认 |
| 16–31 | 战斗画面的大机体图（以拼图形式存放） |

## 音乐（`node tools/extract-music.js`）
- 驱动在 bank 24，NMI 每帧调 `$8020`；往 `$4C` 写 `$80+曲号` 切歌（`$F8–$FE` 是淡出等命令），`$52` 是当前曲号
- 曲目表：bank 0 `$8000` 的指针 → 每首 12 字节（4 字节参数 + 4 个声道的数据指针），共 `$15` 首；读谱时临时把 bank 0/1 换到 `$8000/$A000`（`$C8D7`）
- 关卡事件脚本指令：`59 曲` 我方回合音乐（`$7529`）、`5A 曲` 敌方回合音乐（`$752A`）、`5B 曲` 立即播放（`FB` 当前 / `FC` 我方 / `FD` 敌方）
- 战斗音乐：bank 6 `$86D2` 表（驾驶员编号 → 曲号），敌方贝克（0x35）放 `$10`，其余按我方驾驶员，查不到放 `$05`
- 标题画面会在 NMI 里定时淡出换曲（播放列表），录音时要拦掉
- 导出结果和场合对应在 `data/music.json`；增强版合成方法见 `tools/lib/music-synth.js`

## 音效（`node tools/extract-sfx.js`）
- 和音乐同一个驱动：往 `$4C` 写 `$01–$1F` 播音效，`$53` 是当前音效优先级（新编号不大于它才播），音效占用的声道在 `$4E–$51` bit7；同时只放一个
- 战斗演出：resource `0x60`/`0x61`（按武器编号）是战斗序列脚本，`F4 xx` 播音效、`F9` 生成动画对象（其中 resource `0x69` 是动画脚本，`FD xx` 播音效）、`FE` 调用子脚本；大炮的开火声在第三套脚本里（`$EAB9`），只能实测
- 用途：`0E` 格斗砍击、`0F` 光束发射、`0A` 实弹/导弹发射、`03` 弹道命中、`16` 大炮开火、`0C` 大炮炸开/光子射线命中、`07` 机枪、`12` 左轮、`06` 离子剑/冷冻光线、`17` 离子波、`02` 击破（地图爆炸）、`1E` 确定、`1F` 菜单光标；取消和地图光标移动不出声
- 升级：系统消息里 `FD CE` 插播 `$0E` 号曲（`$C0` 以上的曲号不覆盖 `$52`，放完接回原曲）；精神指令的提示没有声音控制码
