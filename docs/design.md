# 设计文档：第2次超级机器人大战 重制版

个人自用的网页重制版。以 FC 原版（外星汉化版）为基础，保留剧情、关卡和角色，在系统、可玩性、操作和表现上做现代化升级。

本文档是开发的依据，有新想法直接改这里。标注「待确认」的内容，要等从 ROM 提取数据后再定。

---

## 1. 设计原则

1. **剧情、关卡、角色、武器保留原版**，这是这款游戏的灵魂
2. **系统做减法**：每个系统都能一句话说清楚，五分钟上手
3. **深度来自选择，不来自数量**
4. **操作和体验全面现代化**，任何操作都不让玩家等
5. **难度可选**，随时自由切换

---

## 2. 原版系统概况（已在模拟器中确认）

- **机体决定战斗数值**：等级、强度（攻击）、防卫、速度、机动（移动力）、HP 来自机体，按成长曲线随等级提升
- 机体有类型（空 / 陆 / 海），决定移动方式
- 驾驶员提供精神点数（SP，也随等级成长）和一组固定的精神指令；敌方首领驾驶员还带有机动、强度、防卫、速度、HP 加成
- 每台机体 **2 种武器**，各有命中、射程，以及按空 / 陆 / 海分开的火力（`---` 表示打不到该地形）
- 精神指令共 19 种，每位驾驶员固定拥有其中几种，不按等级学会；SP 不够时贵的精神用不了，看起来像「还没学会」（详见 docs/notes-units.md）
- 地图菜单：移动 / 精神 / 状态
- 第一关：第1篇「救出刚达Z」

---

## 3. 核心系统

### 3.1 机体
- 属性沿用原版：等级、强度、防卫、速度、机动、HP、精神点数、类型
- 升级成长、经验值规则沿用原版（公式「待确认」）
- 变形、合体（如有）保留，作为形态切换：换形态会同时换武器和地形适性

### 3.2 武器
- **原样保留原版武器**：名称、命中、射程、空 / 陆 / 海火力
- 有的机体靠射程区分近战和远程，有的靠伤害和命中的差异区分，这些取舍原版已经做好了
- 攻击时根据目标所在地形选用对应火力

### 3.3 精神指令
- 沿用原版：19 种，属于驾驶员，消耗 SP，效果和数值见 data/spirits.json

### 3.4 机师特性（新增）
- 原版驾驶员只有 SP 和精神指令，重制版再给每位驾驶员 **1 个被动特性**，增加角色个性，不改变原版数值结构
- 特性在原版公式算完之后再加减；精神指令「必杀」「回避」仍然优先。敌方 AI 评估攻击时也会考虑特性
- 初版（2026-10-22）按原作形象、驾驶的机体和自带精神分配，数值和分配都在 `data/pilot-traits.json`，边玩边改：

| 特性 | 效果 | 分配 |
|---|---|---|
| 新人类 | 命中 +10，敌人对他的命中 −10 | 大卫、卡姆、克娃、伊娃 |
| 热血 | HP 30% 以下时伤害 +20% | 加代、布西 |
| 斗志 | 每击破一个敌人 SP +5 | 龙、希塔、普西 |
| 快攻 | 速度 +10（影响命中、回避和速度差再攻击） | 欧文、布克、弗兰克 |
| 铁壁 | 受到的伤害 −10% | 路易、卡尔 |
| 根性 | HP 30% 以下时受到的伤害 −20% | 杰克、马丁、珍妮 |
| 神射 | 射程 2 以上的武器命中 +10 | 萨米、尼娜 |
| 支援 | 每回合开始 SP +5 | 由美、发、米奇尔 |
| 指挥 | 周围 2 格内的我方单位命中 +5 | 乔 |
| 底力 | 每回合开始回复 5% HP | 安东、米亚 |

### 3.5 改造（新增）
- **机体改造**：一次提升 HP、防卫、速度，共 10 段（二周目起 15 段）
- **武器改造**：两种武器共用一个等级，提升火力，共 10 段（二周目起 15 段）
- 某台机体改满后奖励一个特殊能力（例如机动 +1，或每回合回复精神点数）
- 改造使用资金，资金来自击破敌人和关卡奖励

### 3.6 战斗规则
- 命中率、伤害公式参考原版（「待确认」，从 ROM 或实测中还原）
- 地形影响防御和回避加成
- 敌方回合我方自动反击；可以给每台机体预设「反击 / 防御 / 回避」
- 攻击前必定显示预测（见 6.3）

## 4. 可玩性

### 4.1 关卡额外目标
- 每关一个，例如「5 回合内通关」「无人被击坠」「击败指定敌人」
- 达成后发奖励：资金、隐藏机体线索、改造奖励；不达成不影响剧情

### 4.2 击坠数与王牌
- 击坠 30 架成为王牌，获得能力加成和专属称号

### 4.3 隐藏要素
- 隐藏机体、角色：满足条件（达成额外目标、说服敌人等）才加入
- 地图上的隐藏道具，需要特定单位走到特定格子

### 4.4 出击选择
- 剧情强制出场的除外，出击前可以自选上场机体

### 4.5 难度
- 简单：敌人弱，适合看剧情
- 普通：接近原版
- 困难：敌人数值更高，AI 会集中攻击残血单位
- **随时自由升降**

### 4.6 不做的
- 回溯 / 悔棋：不做

## 5. 二周目及以后

### 5.1 继承
| 内容 | 继承 |
|---|---|
| 资金 | 全部 |
| 改造段数 | 全部 |
| 击坠数 | 全部 |
| 图鉴、隐藏要素解锁记录 | 全部 |
| 机体等级 | 不继承，保留成长乐趣 |

### 5.2 二周目新增
- 敌人强化：每多一周目提高一档
- 改造上限：10 段提高到 15 段
- 一周目没拿到的隐藏机体可以加入
- 额外关卡：在剧情中插入 3–5 个新关卡，新机体在这里登场
- 新的、更难的关卡额外目标

### 5.3 关卡挑战模式（选关）
- 通关后开放，重玩任意已通过的关卡，独立于剧情存档
- 两种玩法：用当前队伍刷资金；用固定配置挑战回合数和被击坠数记录

### 5.4 新机体
- **暂缓**：先完成原版内容的重制，新机体以后再定（来源：其他机战作品或原创）
- 二周目额外关卡登场，数值风格和原版保持一致：2 种武器、空陆海火力

## 6. 操作与体验优化

目标：**任何操作都不让玩家等，不出现无意义的黑屏和停顿。** 原版很多拖慢节奏的地方来自 FC 硬件限制，例如点机体时黑屏一下（换整屏画面必须先关显示再重画），重制版没有这些限制。

### 6.1 去掉黑屏和停顿
- 状态、精神、武器等窗口直接叠在地图上滑出，不切换整个画面
- 必须切场景的地方（进战斗、进间章）用 0.15–0.3 秒淡入淡出
- 地图平滑滚动

### 6.2 输入响应
- 按键当帧生效
- 光标 8 方向移动，长按加速，起步停顿可调；按住某个键高速移动
- 一键跳到下一个未行动的我方单位
- 菜单记住上次的光标位置
- 移动后可以直接点射程内的敌人发起攻击，省去中间菜单
- 行动确认前随时可以取消移动
- 鼠标：点单位选中、点格子移动、点敌人攻击、悬停看信息、右键取消、滚轮缩放
- 触屏：点按同鼠标，长按取消，双指缩放
- 手柄：完整支持
- 按键可自定义

### 6.3 信息可见
- 地图单位头顶显示小血条，已行动单位变灰
- 一键显示全部敌人攻击范围，可以常驻
- 光标停在单位上自动显示简要资料
- 选中单位后显示移动路线箭头
- 攻击预测：双方伤害、命中率、是否击破、是否反击
- 常驻显示回合数和胜利条件

### 6.4 节奏
- 文字速度三档加瞬间显示；按住快进；已读对话可跳过
- 对话记录（回看剧情）
- 敌方回合 1 / 2 / 4 倍速或直接跳过，镜头只停在发生战斗的地方
- 战斗演出：完整 / 简略两档（没有「关闭」），在设置里切换，默认完整。「简略」= 地图战斗面板（血条、飘字、闪白、震屏）；「完整」= 原版战斗画面：原版机体大图和武器特效按原版位置、逐帧时间播放（远距离的镜头平移也照原版），重制版加了命中闪白震动、落空闪避、伤害数字、血条、连环爆炸，截掉特效播完后的空等（src/remake/battle-scene.ts）。按住快速键 3 倍速，按确定 / 取消或点一下跳过整场（直接出结果）
- 我方全员行动完后自动结束回合（可选）

### 6.5 存档
- 每个我方回合开始时自动存档
- 地图上随时中断存档
- 多存档位，带截图、关卡名、回合数

### 6.6 间章与界面
- 改造界面显示改造前后数值对比
- 出击选择可按等级、HP、击坠数排序
- 机体、角色图鉴
- 设置即时生效

### 6.7 性能与平台
- 稳定 60 帧，高刷新率屏幕上动画跑到 120 帧
- 打开网页 2 秒内可玩
- 可安装为桌面或手机应用，离线可玩
- 手机横屏、触屏完整支持
- 切到后台自动暂停

### 6.8 原版体验问题清单
P0 阶段用模拟器把原版完整玩一遍，记录每一处影响体验的地方，逐条在重制版中解决。

| 原版问题 | 重制版做法 |
|---|---|
| 点机体、看状态时黑屏一下 | 窗口叠加在地图上滑出（6.1） |
| 不支持斜向移动光标 | 8 方向移动（6.2） |
| 按住方向键起步停顿长、移动慢 | 可调的光标加速（6.2） |
| （玩的过程中继续补充） | |

## 7. 表现升级

| 项目 | 做法 |
|---|---|
| 画面 | 先全部用原版像素（整数倍放大）把游戏跑通；最后统一重新绘制一次，不做中间的算法放大。重绘后设置里可切换原版 / 重绘版 |
| 动画 | 全部 60 帧：单位平滑移动、光标缓动、受击震动、数字跳动 |
| 战斗演出 | 完整 / 简略两档，都已完成。完整版用从 ROM 提取的原版机体大图和武器特效 |
| 音乐 | 默认使用从模拟器录制的原版曲目，以后可换编曲版 |
| 界面 | 中文，清晰的数据面板和攻击预测窗口 |

---

## 8. 技术方案

- 网页技术：TypeScript + Canvas 渲染引擎（Phaser 或 PixiJS，P1 时选定）
- 所有内容数据化：机体、武器、精神指令、机师特性、关卡、剧情都是 JSON 文件，改数值、加机体不用改代码
- 素材分层：`assets/original/`（从 ROM 提取）与 `assets/hd/`（高清替换）并存，按设置加载
- 原版模拟器（`src/emu`、`src/player`）保留，作为对照原版的参考工具

## 9. 开发路线

| 阶段 | 内容 | 完成标志 |
|---|---|---|
| **P0 数据提取** | 提取地图、机体、武器、精神指令、驾驶员、敌人配置、剧情文本；还原原版规则；整理体验问题清单 | 全部关卡数据变成 JSON |
